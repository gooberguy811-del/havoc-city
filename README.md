# Havoc City

An open-world driving game: cars, bikes, planes, helicopters, tanks, missions, stores to rob and online play with friends.

**Play:** https://gooberguy811-del.github.io/havoc-city/

Install it as an app from the browser: Chrome / Edge "Install" button, Safari File > Add to Dock (Mac) or Share > Add to Home Screen (iPhone / iPad).

Sound effects are CC0 recordings from freesound.org (full list in the game's Settings). three.js and PeerJS are MIT licensed.
