# Havoc City

An open-world driving game: cars, bikes, planes, helicopters, tanks, missions, stores to rob and online play with friends.

## Play

**https://gooberguy811-del.github.io/havoc-city/**

It runs in any modern browser, on computers, phones and tablets. To get an app icon:

- **Chrome / Edge:** click the Install icon at the right end of the address bar
- **Safari on Mac:** File > Add to Dock
- **iPhone / iPad / Android:** Share > Add to Home Screen

Once opened, it also plays offline. Every time it starts with a connection, it loads the newest version.

## Download

- **[Havoc-City.html](Havoc-City.html)**: the whole game in one file. Download it and double-click it to play in your browser. It needs an internet connection the first time it loads.
- **Mac app:** see [source/macapp](source/macapp). It loads the newest version from the website every time it opens.

## Playing with friends

Use **Play online** in the menu and share the code. The website, the Mac app and the HTML file all play together, as long as everyone is on the same version (the website and the Mac app always are).
